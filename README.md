## Descripción del proyecto

El proyecto consiste en desarrollar un sistema de gestión de vehículos para la agencia automotriz AutoMundo S.A. de C.V.

El sistema permite registrar, consultar, visualizar y eliminar diferentes tipos de vehículos utilizando conceptos de Programación Orientada a Objetos.

---

## Tipos de vehículos

El sistema trabaja con tres tipos de vehículos:

- Automóviles
- Motocicletas
- Camiones

Cada tipo de vehículo posee características generales y características propias de su categoría.

---

## Funciones del sistema

El programa cuenta con las siguientes opciones:

1. Registrar automóvil
2. Registrar motocicleta
3. Registrar camión
4. Mostrar vehículos registrados
5. Buscar vehículo por código
6. Eliminar vehículo por código
7. Salir
